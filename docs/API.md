# Book Worm API reference

Base URL: `http://localhost:8080`. Interactive docs: `/swagger-ui.html`. OpenAPI JSON: `/v3/api-docs` (generated by the running app).

**Auth:** `POST /api/auth/login` returns a `token`. Send `Authorization: Bearer <token>` on endpoints marked **User** or **Admin**. Tokens last 24 hours.
**Errors:** every error returns `{timestamp, status, error, message}`. Codes used: 400 validation, 401 not logged in, 403 not admin, 404 not found, 409 conflict (duplicate, stock, bad state).
**Demo logins:** `admin@bookworm.com / Admin@123` (Admin), `demo@bookworm.com / Demo@123` (User, 500 gift points, one delivered order).

## Cart, coupons and shipping rate (slides 7-8)
| Method | Path | Access | Body / params | Success |
|---|---|---|---|---|
| GET | `/api/cart` | User | optional `couponCode`, `giftPoints` to preview totals | 200 `{items, pricing}` |
| POST | `/api/cart/items` | User | `{bookId, quantity 1-20}` (adds to existing) | 200 cart; 409 over stock |
| PUT | `/api/cart/items/{bookId}` | User | `{quantity}` | 200 cart |
| DELETE | `/api/cart/items/{bookId}` | User | - | 200 cart; 404 if not in cart |
| DELETE | `/api/cart` | User | - | 200 empty cart |
| POST | `/api/coupons/validate` | Public | `{code, orderAmount}` | 200 `{code, valid, discount, message}` |
| GET | `/api/shipping/rates` | Public | `pin` (6 digits), `orderAmount` | 200 `{charge, estimatedDays, estimatedDelivery}` |

**Pricing rules:** tax 12% of subtotal; delivery Rs.40, free from Rs.500 subtotal; coupon discount applies before gift points; 1 gift point = Rs.1; you earn 1 point per Rs.50 paid.
**Seeded coupons:** `WELCOME100` (Rs.100 off, min Rs.300), `BOOK10` (10%), `FESTIVE20` (20%, min Rs.1000), `EXPIRED50` (expired, always rejected).

## Orders, payment, shipping (slides 9-11, 3 steps 9-12)
| Method | Path | Access | Body / params | Success |
|---|---|---|---|---|
| POST | `/api/orders/checkout` | User | `{addressId, couponCode?, giftPoints?}` (uses the cart) | 201 order in `PENDING_PAYMENT` |
| POST | `/api/orders/{id}/payment` | User | see below | 200 `{payment, order}` |
| GET | `/api/orders` | User | - | 200 order history, newest first |
| GET | `/api/orders/buy-again` | User | - | 200 books you purchased |
| GET | `/api/orders/{id}` | User | - | 200 (`cancellable` flag included) |
| GET | `/api/orders/{id}/payments` | User | - | 200 payment and refund records |
| POST | `/api/orders/{id}/cancel` | User | - | 200; allowed while pending, or within 48h of confirmation and before shipping; else 409 |
| POST | `/api/orders/{id}/return` | User | - | 200; only for `DELIVERED` orders; else 409 |
| GET | `/api/orders/{id}/shipment` | User | - | 200 `{status, trackingNumber, estimatedDelivery}` |

**Payment body:** `{method: CREDIT_CARD\|DEBIT_CARD\|UPI\|WALLET, ...}`
- Cards: `cardNumber` (16 digits), `nameOnCard`, `cvv` (3 digits), `expiry` (`MM/YYYY`, not past). A card ending in `0000` is declined (payment `FAILED`, order stays pending, you can retry).
- UPI: `upiId` like `name@bank`. Wallet: `walletId`.
- The gateway is simulated. On success: stock is reduced, gift points are applied and earned, the cart is cleared, and a shipment is created (`PROCESSING`).
- Cancel and return restock the books, refund the payment (a `REFUNDED` record), restore redeemed points and remove earned points.

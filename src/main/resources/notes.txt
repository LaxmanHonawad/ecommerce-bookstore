1. Member

POST, /api/auth/register
Purpose: Create a new customer account and return an auth token (user is logged in immediately).
Request:
{
  "name": "Laxman Honawad",
  "email": "laxman@gmail.com",
  "password": "1234567890"
}

Response:
{
  "token": "6628440207a6ebf55910388f663d81b2c0576a8a24d006158f2350581d325521",
  "expiresAt": "2026-11-09T13:26:08.322235800Z",
  "user": {
    "id": 3,
    "name": "Laxman Honawad",
    "email": "laxman@gmail.com",
    "role": "CUSTOMER",
    "giftPoints": 0
  }
}


POST, /api/auth/login
Purpose: Authenticate with email and password and return a Bearer token to use in the Authorization header.

Request:
{
  "email": "laxman@gmail.com",
  "password": "1234567890"
}

Response:
{
  "token": "4fbcc3dc109a896e6cd2e84e63f2aef7da8cb833c61077096366897ca7145c66",
  "expiresAt": "2026-11-09T13:29:53.620820600Z",
  "user": {
    "id": 3,
    "name": "Laxman Honawad",
    "email": "laxman@gmail.com",
    "role": "CUSTOMER",
    "giftPoints": 0
  }
}


POST, /api/auth/logout
Purpose: Invalidate the current Bearer token (log the user out).

pass token in headers

Purpose: Get the logged-in user's profile (name, email, role, gift points).
